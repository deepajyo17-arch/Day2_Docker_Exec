**Docker Hello World**

Objective:
To verify that Docker is installed and running correctly by executing the Hello World container.

Command Executed
docker run hello-world

Explanation
docker run creates and runs a container from an image.
hello-world is the Docker image used for this exercise.
Docker downloads the image if it is not available locally.
The container prints a message confirming that Docker is working.

Result
Successfully executed the Hello World container using PowerShell.
